# Some Repositories 👀
## Game Development Projects: 🎮
- [Pose Pose Execution - Ubisoft Game Lab Competition 2026](https://flyingsheep22.itch.io/pose-pose-execution) 🏆 : **Won Best User Experience and the Public Choice Award**, and was nominated for 6 other awards, including Best Prototype and Best Technical Challenge & Innovation. Pose Pose Execution is a 1v1 local multiplayer dance battle in Unity. Each round, both players secretly input 4 moves on their Xbox controller, then watch them play out: each move can inflict, block or charge, and your previous move in the round matters, a bit like a more complex rock paper scissors. This was my second Game Lab with a McGill team of 8 (4 programmers), and this time I was the **programming lead**. At the start, I worked on the **architecture** of the input and execution phase systems, and I built the **BeatManager**, which keeps the activation and animation of every object in sync with the music and lets players input their moves on the beat. As the project matured, my role became coordination: making sure every programmer had a task they wanted, that the designers' needs were met and that the artists' work made it into the game. Above all, I kept our **main branch** working: merging everyone's features, reviewing code on GitHub and making sure our main scene had the newest features without breaking.
